# Treasure Hunt – Java Game

## 🎮 About
**Treasure Hunt** is a 2D adventure RPG game made in **Java**.  
I created this game using a **tutorial by Ryisnow** as a guide ([Ryisnow YouTube Tutorial](https://youtube.com/playlist?list=PL_QPQmz5C6WUF-pOQDsbsKbaBZqXj4qSq&si=dZnSCQKem8zx-CRJ)) and added my **personal touches**, including new items, enemies, and interactive features, including new items, enemies, and interactive features. Players explore a **tile-based world**, fight monsters, collect items, interact with doors and chests, and finally discover the hidden treasure. The game is built using **object-oriented programming principles**, making it a fun and structured project for learning Java.

---

## 🕹️ How to Play
- **Move Player:** `W` (up), `A` (left), `S` (down), `D` (right)  
- **Attack:** `ENTER` → Sword attack  
- **Fireball Attack:** `F` → Uses mana  
- **Defense Mode:** `R`  
- **Open Inventory:** `C`  
- **Equip Items:** `ENTER` in inventory  
- **Interact with Objects:** Move close and press `ENTER`

### 🔹 Tips
- Use **Axe** to cut dry trees  
- Use **Key** to unlock doors  
- Collect **Coins, Hearts, and Mana Crystals** to survive and upgrade  
- **Lantern** is needed to explore the dark dungeon  
- Chests contain rewards and are opened only once  

---

## 🗺️ Game Features
- Tile-based world with multiple levels  
- Combat system with Sword and fireball attacks  
- Interactive environment: doors, trees, chests, and merchants  
- Inventory and equipment system  
- Dungeon exploration with hidden treasures  
- Coins, items, and power-ups to enhance gameplay

## 🛠️ How to Run
1. Clone or download the repository  
2. Open in **IntelliJ IDEA** (or any Java IDE)  
3. Make sure **`src/`, `res/`, and `Treasure Hunt/data/`** are in the project  
4. Run the **`GamePanel`** or main class to start the game  

> ⚠️ Make sure **Treasure Hunt folder** is present with `data` and `project.conf` — the game will not run without them.
